# نَبْر — وكيل المعالجة الصوتية المحلي

هذه نسخة محلية أولية قابلة للتشغيل بأسلوب **one double-click** عبر الملف:

`launch_nabr.bat`

## ما الذي تفعله النسخة الحالية؟
- رفع ملف صوتي محليًا
- فهم الطلب بصياغة طبيعية عربية/إنجليزية بسيطة
- تنفيذ سلسلة معالجة صوتية عملية تشمل:
  - تقليل ضوضاء الخلفية
  - حذف السكتات الطويلة
  - قص الصمت من البداية والنهاية
  - موازنة مستوى الصوت
  - تحسين وضوح الكلام بدرجة أولية
- تصدير نسخة WAV نهائية جاهزة للتنزيل

## ملاحظات مهمة
- أفضل دعم مضمون في هذه النسخة: **WAV**
- بعض الصيغ مثل MP3 / M4A قد تحتاج **FFmpeg** مثبتًا على ويندوز
- إزالة الصدى الاحترافية الكاملة ليست مفعّلة بعد في هذه النسخة الأولى
- المعالجة تتم محليًا داخل جهازك

## التشغيل
1. فك الضغط عن الملف ZIP
2. افتح المجلد
3. شغّل `launch_nabr.bat`
4. في أول مرة سيقوم بإنشاء البيئة وتثبيت المكتبات ثم يفتح التطبيق على المتصفح

## ما الذي أضفته فنيًا؟
- FastAPI backend
- واجهة HTML/CSS/JS حديثة عربية
- محرك أوامر بسيط يترجم الطلب النصي إلى عمليات صوتية
- إخراج نهائي WAV

## التطوير القادم المقترح
- waveform حقيقي قبل/بعد
- سحب وإفلات احترافي
- presets أعمق: بودكاست / اجتماع / محاضرة / سوشيال
- إزالة صدى أكثر احترافية
- قص تلقائي ذكي للكلمات المتكررة أو الحشوات
- تغليف EXE لاحقًا بدل الاعتماد على Python المثبّت
